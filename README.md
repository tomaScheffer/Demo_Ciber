# Demo_Ciber — Seguridad en APIs

Proyecto académico de demostración de vulnerabilidades en APIs.

Casos seleccionados:
- BOLA — Broken Object Level Authorization.
- Broken Authentication.
- SSRF — Server-Side Request Forgery.

Estado: planificación inicial. Las demos todavía no están implementadas.

El laboratorio utilizará únicamente datos ficticios y un entorno controlado.
No está destinado a producción ni a realizar pruebas sobre sistemas de terceros.
